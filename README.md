A one-line farewell from a phone dying at 1 percent battery, written for make.fun's "Famous Last Words at 1 Percent" bounty. The phone speaks in its own voice: it stayed at 1% on purpose, just to watch its owner panic.

## Run it

```sh
python3 main.py
```

The program writes the line to /output/entry.txt.
